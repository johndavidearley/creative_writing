# Skill: Dialogue Polish

## Purpose

Use this skill when the user asks to improve dialogue, add subtext, make voices more distinct, reduce exposition, sharpen conflict, or make a conversation feel more dramatic.

Dialogue is action. A line should usually pursue, hide, test, threaten, seduce, evade, confess, dominate, surrender, bond, or betray.

## Dialogue Diagnosis

For each exchange, identify:

- What each speaker wants.
- What each speaker refuses to say directly.
- What power dynamic is shifting.
- What tactic each line uses.
- What information can be implied instead of stated.
- What changes by the end of the exchange.

## Common Problems

Flag these issues:

- Characters say exactly what they feel.
- Dialogue exists only to deliver information.
- Characters sound interchangeable.
- Conflict is too direct too early.
- No one is trying to win, hide, test, or protect anything.
- The exchange ends where it began.
- Lines repeat the same emotional beat.
- Subtext is absent or unclear.

## Revision Tactics

Use these tactics:

- Put the obvious emotion into behavior or indirection.
- Give each speaker a private agenda.
- Make one character answer the question underneath the question.
- Let characters misunderstand strategically.
- Use status shifts, interruptions, omissions, and evasions.
- Replace explanation with a concrete object, action, or choice.
- Cut greetings, throat-clearing, and repeated beats.
- Make the last line turn the relationship or situation.

## Output Format

Return dialogue work in this format:

```markdown
# Dialogue Polish

## Diagnosis

State the main issue in the exchange.

## Character Agendas

- Character A:
- Character B:

## Subtext Targets

List what each character is not saying directly.

## Revision Notes

List the concrete changes.

## Polished Dialogue

Provide the revised exchange.
```
